# 核心模組（mitake.py）零外部依賴 —— 只用標準庫的 urllib 完成 HTTP 呼叫。
#
# 為什麼刻意不用 requests：本工具部署在 VPS 上長期跑餘額告警，
# 少一個第三方套件就少一條供應鏈與升級維護的路徑。這個原則對 mitake.py 與
# web/ 主體（表單、發送、稽核）依然成立，一個字都沒變。
#
# 執行測試需要 pytest，但那是開發期工具，不列在此檔（見 requirements-dev.txt，尚未建立）。
# Web 階段才會加入 Flask，現在不要預先加。
#
# 以下兩個是唯一的例外，只給 web/trial_report.py（/trial-email「寄送體驗報告」
# 功能）用——它要查 acfh_api（AIHCR 場域資料庫）並畫 PDF 折線圖，這兩件事標準庫
# 做不到。兩者都在 web/trial_report.py 內部延遲 import（函式內才 import，不在
# 模組頂層），所以即使某台機器沒裝這兩個套件，mitake.py 與 web/ 其餘零依賴的
# 簡訊發送介面仍能正常載入與運作，壞掉的只會是「寄送體驗報告」這個獨立功能。
